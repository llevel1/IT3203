History of the Web Browser

Early Web Creation

The first web browser and web page editor was WorldWideWeb, written by Sir Tim Berners-Lee in late 1990. It was originally designed for NeXT computers at CERN. The browser was part of the larger creation of the World Wide Web, which was intended to make information sharing easier and more open.

First Browsers

After WorldWideWeb, the Line Mode Browser became important because it could work on different operating systems. It was designed to be simple enough to run on many computers and used a command-line interface that displayed only text. Nicola Pellow helped develop and release it in 1991.

In 1993, the source code for WorldWideWeb was released into the public domain to support the idea that the web should be accessible to everyone. In 1994, WorldWideWeb was renamed Nexus Browser to reduce confusion between the browser and the broader web itself, although it was later discontinued.

The First Browser War

In 1994, Netscape Navigator was released and quickly became popular because it could display text and graphics while the page was still downloading. That made browsing faster and more convenient for users. In 1995, Microsoft released Internet Explorer with Windows, beginning the first browser war between Netscape and Microsoft.

Netscape and Microsoft repeatedly released new versions through the rest of the decade. Internet Explorer’s free distribution with Windows gave Microsoft a major advantage, while Netscape could not match that business model. This contributed to Netscape Navigator’s decline.

The Second Browser War

In 1998, Netscape open-sourced its code and handed it to the Mozilla Foundation, which later released Mozilla Firefox. The second browser war involved more than two competitors and included Internet Explorer, Firefox, Safari, and Opera. During this period, browsers competed by adding features such as reopening closed tabs, spell checking, and HTML video support.

Modern Browsers

The paper notes that Safari was first released in 2003, Firefox in 2004, and Chrome in 2008. Opera had been around since 1994 and became known for simple features and support for portable devices. Microsoft eventually ended Internet Explorer support and shifted to Edge in 2020, using Blink instead of EdgeHTML.

Current Browser Landscape

Although hundreds of browsers have existed, the current market is concentrated in a small number of major products. According to the paper’s StatCounter summary for January 2026, Chrome held 71.36% of global browser market share, Safari held 14.77%, Edge held 4.65%, Firefox held 2.23%, and Opera held 1.88%. The paper argues that this pattern reflects not only technical quality but also default placement, platform ecosystems, and integration with operating systems and cloud services.

Conclusion

The browser helped transform the internet from a technical network into an everyday tool for communication, learning, and access to information. The paper describes it as a revolutionary technology and even as a “killer app” because of how central it became to modern digital life.
